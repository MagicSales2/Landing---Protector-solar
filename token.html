Generador de token

Se genera en tu navegador. No se envía a ningún servidor.

generando…

  1. Copiá el token.
  2. Abrí tu Google Sheet → Extensiones → Apps Script.
  3. En la línea que dice token:, borrá el valor viejo y pegá el nuevo.
  4. Implementar → Nueva implementación → Aplicación web → Nueva versión → Cualquier usuario → Implementar.
  5. En Supabase → Table Editor → tabla config_sheets → fila clave = token → pegá el mismo token → Guardar.
  6. Cerrá esta página.
Esta página desaparece cuando termines. El token no queda guardado en ninguna parte: solo existe en tu pantalla hasta que lo pegues en los dos sitios de arriba.
